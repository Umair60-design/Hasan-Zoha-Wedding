HASAN & ZOHA — FREE WEDDING INVITATION
===========================================

Open index.html in a browser to preview the invitation.

FREE PUBLISHING:
1. Create a free GitHub account at https://github.com/
2. Create a new repository named: hasan-zoha-wedding
3. Upload index.html and hero.svg.
4. Go to Settings -> Pages.
5. Under Build and deployment, choose "Deploy from a branch".
6. Choose the main branch and / (root), then Save.
7. GitHub will give you a free invitation URL.

CUSTOMIZATION:
- The main content is all in index.html.
- Replace hero.svg with a photo if desired; rename your photo to hero.jpg and change hero.svg to hero.jpg in the CSS.
- The Google Maps embed is already included using the exact map code supplied for United Palace Gold.
- Countdown is set for 17 March 2027 (India time).

No paid website builder is required.
